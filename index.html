Quên mật khẩu?

Nhân viên quên mã PIN

Báo quản trị viên. Admin vào Quản lý Tài khoản → bấm sửa tên bạn → đặt PIN mới. Đăng nhập xong bạn tự đổi lại PIN trong Cài đặt (biểu tượng bánh răng).

Quản trị viên quên mật khẩu

  1. Đăng nhập Netlify, mở site này → Site configuration → Environment variables.
  2. Thêm (hoặc sửa) biến ADMIN_PASSWORD với mật khẩu mới.
  3. Deploy lại site. Mật khẩu mới thay cho mật khẩu cũ.
